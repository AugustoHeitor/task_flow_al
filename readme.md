# TaskFlow AI

**TaskFlow** é um gerenciador de tarefas inteligente que utiliza Inteligência Artificial para facilitar a organização e o gerenciamento de atividades por meio de uma interface conversacional.

O projeto integra um agente de IA capaz de interpretar solicitações em linguagem natural e executar operações diretamente no sistema.

### Funcionalidades

- **Gerenciamento de tarefas:** criar, listar, editar e excluir tarefas.
- **Assistente com IA:** interação por linguagem natural utilizando Google Gemini.
- **Agente inteligente:** execução de ações por meio de ferramentas (AI Tools).
- **Memória conversacional:** persistência do histórico de conversas.
- **Kanban:** organização de tarefas por status.
- **Multiusuário:** gerenciamento de tarefas isoladas por usuário.
- **Human-in-the-Loop:** confirmação de ações importantes antes da execução.

### Tecnologias

- **Backend:** Node.js, Express.js
- **IA:** LangChain, Google Gemini
- **Banco de dados:** MySQL e PostgreSQL
- **Frontend:** JavaScript, HTML5 e CSS3
- **Comunicação:** Socket.IO

### Objetivo

Explorar a integração de LLMs, agentes inteligentes, ferramentas e memória conversacional em uma aplicação real, demonstrando como a Inteligência Artificial pode transformar a interação com sistemas tradicionais.
